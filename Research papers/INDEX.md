## 7. Datasets and annotation schemes (11)

Supplies the supervision the Gate-0 data contract requires. LongMemEval and LoCoMo live in §2 as end-to-end benchmarks.

### Proof-set supervision (Stage D)

- [Constructing A Multi-hop QA Dataset for Comprehensive Evaluation of Reasoning Steps](07_Datasets/01_2WikiMultiHopQA_COLING_2020.pdf) (2WikiMultiHopQA) — COLING 2020 — **Core** — 192,606 examples; evidence annotated as (subject, property, object) Wikidata triples forming a reasoning path; evidence F1 is an official metric (human 78.81 vs baseline 14.94)
- [MuSiQue: Multihop Questions via Single-hop Question Composition](07_Datasets/02_MuSiQue_TACL_2022.pdf) — TACL 2022 — **Core** — MuSiQue-Ans ~25K, MuSiQue-Full ~50K with answerable/unanswerable contrast pairs; trains the answerability gate (plan §4.2)
- [HotpotQA: A Dataset for Diverse, Explainable Multi-hop Question Answering](07_Datasets/03_HotpotQA_EMNLP_2018.pdf) — EMNLP 2018 — **Baseline** — sentence-level supporting facts; the testbed the submodular/PCST baselines are tuned on

- [Dialogue-Based Relation Extraction](07_Datasets/04_DialogRE_ACL_2020.pdf) (DialogRE) — ACL 2020 — **Core** — D3; 1,788 dialogues, 10,168 triples, 36 relations; use the progressive **F1_c** metric
- [Conversational Entity Linking: Problem Definition and Datasets](07_Datasets/05_ConEL_SIGIR_2021.pdf) (ConEL) — SIGIR 2021 — **Core** — D1 task definition
- [Personal Entity, Concept, and Named Entity Linking in Conversations](07_Datasets/06_ConEL2_CREL_CIKM_2022.pdf) (ConEL-2 / CREL) — CIKM 2022 — **Core** — D1; personal entities ("my car") match the `CREATE_NEW_ENTITY` action

- [TORQUE: A Reading Comprehension Dataset of Temporal Ordering Questions](07_Datasets/08_TORQUE_EMNLP_2020.pdf) — EMNLP 2020 — **Core** — D4; 3.2k snippets, 21k questions
